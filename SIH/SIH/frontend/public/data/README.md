# Map boundary provenance

`india-official-boundary.geojson` is a line-only, 1.5 km simplified conversion of the
Survey of India **Official Boundary of India** generalized 1:16M digital dataset.

- Source: `https://surveyofindia.gov.in/documents/OUTLINE_OF_INDIA_SHP.zip`
- Publisher: Survey of India, Department of Science & Technology, Government of India
- Intended use here: non-commercial hackathon/educational website display
- Conversion: `scripts/convert_soi_boundary.py`

No administrative analytics use this asset. It is a visual overview overlay only.
